# If you are using an ESP32 dev module upload the .ino file

## Setup the ESP32

### Go to *Board Manager* and install the *ESP32 board manager*

### Go to *tools* and select the *ESP32 board* and then under that select *ESP32 dev module*

## Install the dependencies

### Go to *Library Manager* and install the *ESP32 dev module*

## If you're computer is not recognizing the ESP32 board then download the *Silicon Labs CP2102x driver*
## Go to the .zip folder and extract the files

## Go to the extracted folder and right click on the .inf file and select the install button

## Go to Device Manager and check whether the ESP32 board is recognized

## Upload the .ino file to the ESP32 board

### Hardware required

- ESP32 dev module
- 3 LED's (Red, Green, Blue)
- 1 DHT sensor
- 1 TFT LCD Screen
- 1 Arduino UNO (if supplying external LiPo battery power)
- 1 LiPo battery (if using external power source)
- USB *D* type cable
- Computer
